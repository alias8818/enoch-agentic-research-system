# Top 5 Things Enoch Should Stop, Avoid, or Defer

1. **Avoid becoming an OpenHands/Devin clone.** Enoch’s advantage is local research-control evidence, not a general software-agent product surface.
2. **Stop treating paper count as quality.** Make negative results, failed mechanisms, and scale-blocked findings first-class outputs.
3. **Defer generic multi-agent role-play orchestration.** Add only when evals show role decomposition improves a measured outcome.
4. **Avoid black-box memory before benchmark design.** Memory must be inspectable, replayable, versionable, and falsifiable.
5. **Defer production speculative decoding.** First measure Enoch-specific repetition/entropy and offline acceptance proxies.
